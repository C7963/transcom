### C# PSCAN 链路（真源）
- InitBaseBand（服务启动无条件执行）：HMC703 config2 → Si5386Init → ADC9695+JESD → **0x000C0005=0 / 0x000C0006=0x4000（扫频 NCO 307.2MHz）** → 0x000C0007=2 → DMA 0x00001040。
- PScan 指令：0x00005010=1；mz121 时 0x000C0007=3 + ADC 0x310=0x47/0x311=0x70；SetOrder(0x00010001/3/4+0x00010000) 下 IFATT/RFATT/WorkMode；SpectrumSweep.Config() 写 0x10010000 块+Blackman(0x10018000)+扫频表（每段 0x00006002/03=64bit RF 频率、0x00006004=校准、0x00006001=0x80000000+i 然后 i）。
- Pscan_BW=80E6（App.config）；RFRBW=10000（mz121）。
- 幅值：20*log10(raw) − ErrorValue + RFModeError + RFatt + IFatt + 107。

### C++ 现状（BSPDriver + PscanTestClient）
- 活动路径：PscanApi_Init → CommonManager::**InitDevice**（通用 Win_API 路径）→ PscanOrder::Handle。
- **InitPscanDevice（C# 风格全量初始化：HMC703 config2 + Si5386 config4 + ADC config2）整体被 `#if 0` 禁用**（CommonManager.cpp:419-463）。
- InitDevice→ADCInit：get_adc_status()==OK 时跳过 Si5386 init_clock；**HMC703（前端 LO PLL）从不配置**。
- **0x000C0005/0x000C0006（扫频 NCO 307.2M）全工程无人写**（grep 无结果），C# InitBaseBand 有写。
- ConfigurePscanHardwareMode / ConfigurePscanCSharpFrontend（0x000A0001/02 前端增益/模式）/ ConfigurePscanRfCenter（RFControl::SetCenterFreq → 0x000A0201/02/00 RF LO）均有定义**无调用点**（Pscan.cpp InitializeState 里调用被注释）。
- PscanOrder/SpectrumSweepFft 的扫频表写入（0x00006001-04、0x10010000、Blackman）与 C# 一致，是好的。
- 差异：C++ context.Pscan_BW=614.4e6 vs C# 80e6；C++ RFRBW=1000 vs C# 10000；C++ PscanErrorValue=0（公式常数 +107）。

### 现象结论
- 921.6MHz = FS_ADC(1.2288G) − 307.2M(NCO)，即 MZ121 前端物理中频。无信号源时 921.6M 中心的峰 = 接收机自身中频/时钟自杂散落入分析窗，只证明数字+时钟链活着，不证明射频前端工作。
- <100M 全噪音：Rf_Sub=180M 以下前端需走低频/直通通道；C++ 从未配置前端（HMC703/0x000A 寄存器/RF LO），无变频增益 → 只剩 ADC 噪声底。
- 当前 C++ 客户端能否看到信号取决于之前跑过的软件留下的寄存器状态（与之前验证的"跨程序状态保持"一致）。
